# N90 Max 探索版 · 车主展厅

这是一个为车主博客制作的静态宣传页，主题是 **N90 Max 探索版升顶 + N70 蝶翼谷蓝灵感配色**。页面保留“外观 → 内饰 → 空间”的展厅节奏，提供视角切换、拖动旋转提示、车主手记与官方展厅入口。

## 官方原站

- [小米汽车 3D 展厅](https://show.xiaomiev.com/v2/showroom?itemId=510036425189&ssuId=610085836993&source=pcn90homepage&operateCar=switch)

本仓库用于车主宣传，不代表小米汽车官方，也不用于商业销售。官方链接用于车型信息与原始展厅入口；本仓库的文字、配色和交互为车主定制内容。

## 本地检查

这是零依赖静态页面。直接打开 index.html，或运行：

    python3 -m http.server 4173

然后访问 http://localhost:4173/。

仓库仅包含 index.html、styles.css、app.js 和本说明文件；未包含 refs/、用户参考 PNG、密钥或个人数据。
